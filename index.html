Apple I

      
Steve Wozniak's first board, hand-built in the Jobs family garage and sold bare — no case, no keyboard, no power supply, no monitor. This page is a working recreation: a real emulated 6502 sits behind a hex monitor you can actually type into.


      

        
CPU
MOS 6502 @ 1 MHz (emulated)

        
Memory
8 KB RAM, $0000–$1FFF

        
I/O
6820 PIA at $D010–$D013

        
Firmware
256-byte monitor, reimplemented in JS

        
Launch price
$666.66, July 1976

        
Units built
≈200, by hand

      


      

        
Using the monitor

        
    
          
  • 0300 — examine one byte, Return again for the next
    • 
          
  • 0300.030F — examine a range
    • 
          
  • 0300: A9 00 8D 12 D0 — deposit bytes from $0300
    • 
          
  • 0300R — run the program at $0300
    • 
        

      


      

        
        
      


      
Click the screen, then type — it's a real line-oriented terminal. Any bytes you deposit and run execute on a genuine (if simplified) 6502 instruction set, not a scripted animation.
